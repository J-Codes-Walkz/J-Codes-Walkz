### 🃏 Featured project: [CardVault](https://github.com/J-Codes-Walkz/CardVault)

A full stack **Django and PostgreSQL** app for Pokémon card collectors: track the cards you own and want, and write reviews. Live on Heroku, and my Code Institute capstone.

- **229 automated tests** at **99% coverage**, with GitHub Actions CI (flake8, tests, Bandit, pip-audit) that must pass before every deploy
- **Security by design:** login rate limiting, a Content Security Policy, HSTS and daily database backups
- **Lighthouse 100** for Accessibility and SEO on every page, and WCAG 2.2 AA with 0 axe violations
- **Built with Claude Code**, with a written log of every AI decision, what was checked, and every AI mistake that was caught
